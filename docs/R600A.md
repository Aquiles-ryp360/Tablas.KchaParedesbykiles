# R600a: tablas digitalizadas y ejercicio flash–binario

Se digitalizaron las cuatro páginas de `tablas.pdf` aportadas por el usuario. Cada tabla tiene 48 filas; las tablas de vapor contienen 21 columnas de sobrecalentamiento, de 0 a 100 °C en pasos de 5 °C. El documento original se identifica mediante SHA-256 en `data/r600a/metadata.json`.

| Archivo CSV | Página | Contenido |
|---|---:|---|
| `saturated.csv` | 1 | Líquido y vapor saturados, presión absoluta, densidad y calor latente |
| `volume.csv` | 2 | Volumen del vapor sobrecalentado, dm³/kg |
| `enthalpy.csv` | 3 | Entalpía del vapor sobrecalentado, kJ/kg |
| `entropy.csv` | 4 | Entropía del vapor sobrecalentado, kJ/(kg K) |

`tables.json` conserva las mismas matrices. `Tablas_R600a_y_calculo.xlsx` presenta las cuatro tablas y una hoja con fórmulas del ejercicio. No se modificó la base SQLite de agua.

## Unidades e interpolación

La página 1 imprime el volumen líquido en **dm³/kg** y el volumen del vapor saturado en **m³/kg**. La página 2 imprime el volumen de vapor sobrecalentado en **dm³/kg**. Para convertir dm³/kg a m³/kg, dividir entre 1000. Las presiones son bar absolutos: 1 bar = 100 kPa.

Las columnas de las páginas 2–4 representan **ΔT = T − T_sat**, no temperatura absoluta. Para consultar una presión intermedia:

1. Localizar las dos filas que encierran la presión.
2. Calcular ΔT con la temperatura de saturación de **cada fila**.
3. Interpolar la propiedad entre las columnas de ΔT de cada fila.
4. Interpolar los dos resultados en presión.

La consulta rechaza extrapolaciones. Para consultar vapor cerca de saturación en una presión intermedia, ambas filas deben cubrir el ΔT solicitado; no se extrapola la fila que quede por debajo de su temperatura de saturación.

```bash
PYTHONPATH=src python -m thermo_solver.r600a --pressure-bar 32.5 --temperature-c 145
PYTHONPATH=src python -m thermo_solver.r600a --pressure-bar 4
python examples/flash_binario_r600a.py
python -m unittest discover -s tests -v
```

La salida P–T incluye las filas, páginas, grados de sobrecalentamiento, extremos y resultados usados en cada interpolación.

## Transcripción y comprobaciones

Se realizaron varias lecturas OCR, corrección de geometría del escaneo, selección entre candidatos observados y revisión visual de discrepancias. Las selecciones automáticas usan continuidad y monotonía como diagnósticos; no generan valores termodinámicos nuevos ni sustituyen celdas por una ecuación de estado. `cell_audit.json` conserva el valor, la posición y los candidatos leídos para las 3888 celdas numéricas, distinguiendo `visual_verified`, `visual_row_label`, `ocr_consensus` y `ocr_selected`.

Se comprobaron dimensiones, orden de presiones, ausencia de celdas vacías, monotonía en sobrecalentamiento, h_fg = h_g − h_f y coincidencia entre vapor saturado y la columna ΔT = 0. Se respetó el redondeo impreso. Las propiedades empleadas en el ejercicio se contrastaron directamente con las imágenes. La transcripción de un escaneo y estas comprobaciones no representan una certificación independiente de cada cifra.

## Ejercicio de 230 °C y 230 kg/s

Se conserva la numeración de la fotografía: 8 entrada de turbina binaria; 9 escape; 10 salida del condensador; 11 salida de bomba. La bomba utiliza líquido incompresible, w_B ≈ v_10 Δp/η_B, con eficiencia 90 %. Las tablas no incluyen líquido comprimido de R600a; por ello no se asignan T_11 ni s_11.

| Resultado | Valor |
|---|---:|
| Caudal de isobutano | 105.535 kg/s |
| Potencia flash | 15.412 MW |
| Potencia neta binaria | 6.167 MW |
| Potencia neta combinada | 21.579 MW |
| Eficiencia binaria | 12.216 % |
| Eficiencia combinada, ambiente a 25 °C | 10.599 % |

La eficiencia combinada usa m_geo(h_1 − h_0), con h_0 = 104.83 kJ/kg a 25 °C. La temperatura ambiental no figura en la fotografía y se declara como supuesto. Si se divide entre la energía efectivamente retirada del recurso se obtiene 14.580 %: es otra base térmica. Se incluye la bomba de isobutano; otros consumos auxiliares no están especificados.

El desarrollo, las interpolaciones, el esquema, los balances y la tabla de estados están en `examples/flash_binario_230C/solucion.pdf`; las cifras sin redondear, en `results.json`.
